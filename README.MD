# Operating Systems – CAT-3 Activities

This repository contains C implementations of five practical activities assigned as part of the **Operating Systems (B.Tech CSE, Semester 5)** coursework.

## Activities

| No. | Activity | Concepts |
|---|---|---|
| 1 | Memory Management Simulator | First Fit, Best Fit, Worst Fit |
| 2 | Virtual Memory and Demand Paging | Page Faults, Page Hits, FIFO |
| 3 | Page Replacement Algorithms | FIFO, LRU, Optimal, Second Chance |
| 4 | Collaborative File System | File Operations, File Locking, Permissions |
| 5 | File System Protection and Security | Authentication, Access Control, Audit Logs |

## Technologies Used

- **Language:** C
- **Compiler:** GCC
- **Platform:** macOS / Linux

## How to Run

Compile any C program using GCC:

```bash
gcc activity1.c -o activity1
./activity1
```

Replace the filename with the required activity's filename.
